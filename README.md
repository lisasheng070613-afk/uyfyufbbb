# 我的小站

一个中文个人主页，包含自我介绍、作品占位与联系区域，适配手机和电脑。使用原生 HTML、CSS 和 JavaScript，无需安装依赖，无外部字体或图片请求。

## 本地运行

在仓库目录执行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

在浏览器访问本机的 8000 端口；也可以直接打开 `index.html`。

## 换成你的内容

- 在 `index.html` 修改站点名称、自我介绍、兴趣和作品信息。
- 两个作品均明确标记为示例；有实际作品后，可添加真实的作品链接。
- 联系区域目前不含虚构邮箱。添加自己的邮箱或社交链接后，替换联系方式占位。
- 在 `styles.css` 的 `:root` 中调整主题颜色。

这是静态页面，没有后端或数据收集功能，可部署到支持静态网站的托管服务。
