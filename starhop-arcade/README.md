# 星跃冒险 · Starhop Arcade

《星跃冒险》是一款 2D 横版像素网页游戏。前七关以跳台跑酷为主，第八关需要躲避弹幕，等守卫护盾消失后反击。击败守卫后会显示「你真棒」。

首次游玩从第 1 关开始，每次通关解锁下一关。八关全部通过后可自由选关。

## 关卡机关

- **第 2 关 · 苔影森林**：遇到蜘蛛群后按住 **D** 向右跑，用 **空格** 跳过断崖、荆棘和沼泽。看到蛛丝提示时按对应方向键，按错或超时会减速。被追上后可从追逐入口重试。
- **第 3 关 · 水晶矿洞**：从上下岔道穿过矿井，躲避升降尖刺、轨道尖刺和下压刺板。
- **第 4 关 · 云端遗迹**：断桥前按 **E** 启动石板，在判定线按下对应方向键，也可点击屏幕箭头。连续命中八个音符会放下吊桥。
- **第 6 关 · 霜月山脊**：沿山脊向上攀登。留意绿翼幼龙的落石，瞄准命中两次可消灭幼龙。山顶牛头人免疫攻击，留意冲撞路线和砸击落点。后半段预警更短，冲撞更快，砸击范围更大。撑过八次攻击后拾取钥匙即可进入第 7 关。
- **第 7 关 · 星轨高塔**：从闸门附近的水洞进入迷宫，用 **A / D** 游动，**↑ / ↓** 上浮或下潜，在气穴补氧。按 **E** 调查白帽拿钥匙，闸门开启后会自动进入终幕。红帽会把你送回水面。
- **第 8 关 · 星铃守卫**：红温阶段的每发弹幕会扣两颗心，继续把握护盾解除的反击窗口。

## 本地游玩

直接用浏览器打开 `dist/index.html`。也可以在仓库根目录运行以下命令，再访问 `http://localhost:8000`。

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

无需安装前端依赖或执行构建。关卡进度保存在当前浏览器中。

| 操作 | 按键 |
| --- | --- |
| 左移 | A |
| 右移 | D |
| 跳跃 | 空格 |
| 瞄准攻击 | 鼠标左键 |
| 交互 | E |
| 暂停或继续 | Esc |
