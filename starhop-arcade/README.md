# 星跃冒险 · Starhop Arcade

《星跃冒险》是一款 2D 横版像素网页游戏。前七关以跳台跑酷为主，第八关需要躲避弹幕，等守卫护盾消失后反击。击败守卫后会显示「你真棒」。

## 本地游玩

直接用浏览器打开 `dist/index.html`。也可以在仓库根目录运行以下命令，再访问 `http://localhost:8000`。

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

无需安装前端依赖或执行构建。关卡进度保存在当前浏览器中。

| 操作 | 按键 |
| --- | --- |
| 左移 | A |
| 右移 | D |
| 跳跃 | 空格 |
| 瞄准攻击 | 鼠标左键 |
| 暂停或继续 | Esc |
